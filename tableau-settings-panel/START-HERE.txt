SETTINGS PANEL FOR TABLEAU DASHBOARDS - QUICK START
====================================================

Needs: Tableau Desktop 2024.2 or newer (the free edition works).
It is a DASHBOARD extension: it goes on a dashboard, not on the Marks card.

1. Unzip this folder somewhere permanent, like your Desktop. Do not run it from inside the zip.

2. Double-click  Start-SettingsPanel.bat
   A black window opens and says "Settings Panel server is running." LEAVE IT OPEN the whole time
   you use the dashboard. Closing it makes the panel go blank.
   (If Windows shows a blue "protected your PC" box: More info > Run anyway.)

3. Open a dashboard. In the Objects pane, set the object to Floating, then drag Extension onto the dashboard.

4. Click Access Local Extensions and pick  settings-panel.trex  from this folder. Click OK to allow it.

5. A gear appears. Click it: every parameter and every filter on the dashboard's sheets is in the panel.
   Floating, the zone grows to the panel when it opens and shrinks back to the gear when it closes.

6. Save a preset on the Presets tab. Presets and the panel's theme are saved inside the workbook.
