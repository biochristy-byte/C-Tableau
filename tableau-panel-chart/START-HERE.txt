PANEL CHART FOR TABLEAU - QUICK START
=====================================

Needs: Tableau Desktop 2024.2 or newer (the free edition works).
Tableau Public: works while you author; viewers see "not supported" until Exchange approval.
For a public audience use the C-Tableau Viz pages instead. See README.md.

1. Unzip this folder somewhere permanent, like your Desktop. Do not run it from inside the zip.

2. Double-click  Start-PanelChart.bat
   A black window opens and says "Panel Chart server is running." LEAVE IT OPEN the whole time
   you use the chart. Closing it makes the chart go blank.
   (If Windows shows a blue "protected your PC" box: More info > Run anyway.)

3. In Tableau, open a worksheet on any data source (Superstore works).

4. Marks card > the mark type dropdown > Viz Extensions > Add Extension
   > Access Local Viz Extensions > pick  panel-chart.trex  from this folder. Click Allow.

5. Drag a dimension onto Category (Region) and a measure onto Value (Sales).
   Optional: a dimension on Color for series (Category), a measure on X value for a scatter (Profit).

6. Hover the chart and click the gear in the top right. Chart type, orientation, sort, stacking,
   labels, axes, gridlines, palette, tooltips, number format, legend and title are all in there.
