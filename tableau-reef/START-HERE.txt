REEF CIRCLE PACKING FOR TABLEAU - QUICK START
==============================================

Needs: Tableau Desktop 2024.2 or newer (the free edition works).
Tableau Public: works while you author; viewers see "not supported" until Exchange approval. See README.md.

0. One time only: download Tableau's Extensions API library into lib/
   (lib/README.md has the link and a one-line command). Without it the chart is blank.

1. Unzip this folder somewhere permanent, like your Desktop. Do not run it from inside the zip.

2. Double-click  Start-Reef.bat
   A black window opens and says "Reef server is running."
   LEAVE IT OPEN the whole time you use the chart. Closing it makes the chart go blank.

3. In Tableau, make a worksheet with a dimension and a measure.

4. Marks card > the mark type dropdown > Viz Extensions > Add Extension
   > Access Local Viz Extensions > pick  reef.trex  from this folder. Click Allow.

5. Drag a dimension onto Level 1, more onto Level 2 and Level 3 if you have them,
   and a measure onto Size. Click a circle group to zoom in, the path at the top to climb out.
   Hover the chart and click the gear for every setting.

Color: Tableau allows four shelves, so color is in the gear panel. Drop a field on Detail,
then Color by > A field from Detail > pick it.

IF THE CHART IS BLANK
- Is the black window still open? Reopen Start-Reef.bat.
- "Port 8770 is already in use"? The server is probably already running. Leave it.
- Is lib/tableau.extensions.1.latest.min.js there? See step 0.
